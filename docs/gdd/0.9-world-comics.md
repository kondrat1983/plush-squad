# v0.9 · Comics for every world (#62)

A short arrival comic for Pillow Hills, Space and Spooky, made with the same engine as the Canada comic, plus a COMICS shelf in the Album with all four. Written by `game-designer` on 5 Oct 2026, from the code on `origin/main` (v0.8.2, commit 03d7236).

Owner decisions this doc follows: comics for every world (Kondrat, 5 Oct 2026, #62); retro comics "Space for everyone, once" and "Pillow Hills for new players" (decisions.md, 4 Oct 2026); bedtime and daily limit apply to every new mode.

## 1. Pitch
Every world now opens with a 10-second comic page: Jack crash-lands, something silly happens, the world's name explodes on screen. Four comics to collect and rewatch in the Album. A 10-year-old cares because the Canada comic is the one part of v0.8 that tells a story, and kids rewatch funny cut-scenes and show them to friends.

## 2. Fit
- Roadmap: v0.9 (with "Together" and #47). Small, art-free. Can ship in pieces (section 8, PR list).
- Depends on: the Canada comic engine (`ComicScene` in `js/game.js`), Album COMICS switch (`js/extra.js`, #54).
- Changes:
  - `ComicScene` becomes data-driven: today the three panels, the `CANADA!` title, the maple-leaf confetti and the Sasquatch peek are hard-coded in `play(i)` and `toTitle()`. `init(data)` already receives `world`, but the scene ignores it.
  - `comicDue()` is Canada-only today. It becomes `comicDue(id)`.
  - The router in `fade()` and `MapScene.create()` check Canada only. Both become generic.
  - The map tab replay (`tab()`: "tap the open tab to replay") works for Canada only. It becomes generic.
  - Album `COMICS` grows from 1 to 4 entries, and the shelf becomes a 2 × 2 grid.
  - Tests: `BASE_SAVE` in `tests/helpers.js` has `comics: { canada: true }`. It must get `hills`, `space` and `spooky` too, or every map test will land in a comic.

### What the code does today (quoted, v0.8.2)

| Title page | `burst('CANADA!')`, `comicSting` + `levelUp`, maple-leaf particles 2.5 s, Sasquatch shows and wobbles in panel 3, button LET'S GO! (DONE! when coming from the Album) |
| Seen flag | `Save.data.comics.canada = true` when the title page shows (SKIP or the end) and on LET'S GO |
| Textures used | `sky4`, `aurora`, `pine`, `jack_side`, `jack_upside`, `jack_front`, `sasquatch`, `moose`, `pancakes`, `mapleleaf`, `dot`, `halftone` |
| Music | `calm` (scene hook); `babble` per bubble |
| Bedtime | `comic` is in the bedtime / daily-limit screen list in `extra.js` |
| Rotation | `snapshot()` keeps `{ world, panel, then }`; panels before `panel` are drawn finished |

### Why 3 panels, not 4
Four stacked panels on iPad portrait would be about 255 px tall, too small for a bubble plus two actors. Four side by side on a 4:3 iPad would be about 315 px wide. So each comic keeps **3 panels plus the title page** (the title burst works as panel 4). Same rects, no layout risk on the 5 sizes.

## 4. Signature mechanic: "when does the comic show"
No duel rule here, so this section covers the trigger. Same rule for all: a comic plays **once, the first time its world opens**, then goes on to where the player was heading (`then`).

| Comic | Due when (`comicDue(id)`) | Entry points | Who sees it |
|---|---|---|---|
| `hills` | `!comics.hills` and the save is brand new (`xp == 0 && wins == 0`, no stars) | first map open (TAP TO PLAY → map) | **new players only** (decision 4 Oct). Older saves: the cover is unlocked in the Album at once, no autoplay |
| `space` | `!comics.space` and `worldOpen(SPACE)` | Space map tab; a Space duel via the router (NEXT RIVAL after Hoot); `MapScene.create` with world Space (restored save, `lastWorld`) | **everyone, once** (decision 4 Oct). Players already past Space see it the next time they open Space |
| `canada` | unchanged | unchanged | unchanged |
| `spooky` | `!comics.spooky` and `EVENT_ON` | Spooky map tab; a Spooky duel via the router | everyone, during the event (1 Oct to 7 Nov) |

Rules:
- One comic per screen change. If two are due (a new player in October: `hills` and later `spooky`), the one for the world being opened plays. Hills comes first because a new player's map opens on Pillow Hills.
- A comic never interrupts a duel. The router only acts on `fade(scene, 'battle', ...)` and map opens.
- Seen flag: same as Canada, set when the title page shows (SKIP or the end).
- Replay: tap the active world tab on the map (generic, every world), or the Album cover.
- EASY / NORMAL / HARD: no difference. Comics are the same on every difficulty.
- Bedtime and daily limit: already covered (`comic` is in the blocked-screen list). If bedtime starts, the comic waits for the next session.
- Rotation: already covered by `snapshot()` (`world` is kept in the scene data).

## 5. Balance
No numbers change. No rival, move, booster, XP or pep values are touched (checked against `RIVALS`, `MOVES`, `DIFFS`, `DEF_W` on v0.8.2). Comics do not answer "too easy"; they answer the tester's wish for more world flavour. No simulation needed.

Time cost for the player: about 9-10 s per comic if nobody taps, one tap to skip. Once per world.

## 6. Rewards and progression
- No XP, capsules or stickers for watching (a comic is a story, not a chore). Optional sticker idea in the decisions list: "Comic Fan" (watch all comics) [?].
- Unlocks: as in section 4. No progression is blocked by a comic.
- Save field: `Save.data.comics = { hills, space, canada, spooky }` (booleans). Cloud save carries it as part of the save. No migration: missing = not seen. Old saves get `comics.hills = true` from the v0.9 migration (so the shelf shows it unlocked), not `space`.
