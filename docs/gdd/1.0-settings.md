# v1.0 · Settings screen

One small screen for things a kid (or a grown-up) wants to change on this device. Written by `game-designer` on 10 Oct 2026, from the code on `origin/main` (v0.9.0, commit a8e0d30). GDD §17 "Launch readiness": music volume, reduce motion, left-handed card layout.

Rules this doc keeps: no parent gate for these (they are not about limits); bedtime and daily limit stay in Parents; nothing online.

## 1. Pitch
A gear button on the title opens SETTINGS: music and sounds louder or softer, Calm mode (less shaking and sparkles), cards on the left-hand side, and a few small extras. A 10-year-old cares because he can turn the music down and keep the sounds on in the car; a 6-year-old who gets dizzy from shaking can play calmly.

## 2. Fit
- Roadmap: v1.0 (owner's scope, 10 Oct 2026). Localisation is after 1.0, so no language option yet.
- Depends on: `js/audio.js` (`init`, `sfxGain`, `musicGain`, `setMuted`), `muteButton()`, `Battle.setup()` card layout and `setCards()` tool buttons, `buzz()`, `sky()`, the plugin `nav` in `js/extra.js`, `whatsNew()`.
- New scene `settings` in `js/extra.js` (next to Parents), using `header()` and the Parents pill style.

### What the code does today (v0.9.0)
| Thing | Today |
|---|---|
| Sound | one mute button top right (`muteButton`), stored in the save as `muted` (synced to the cloud) |
| Gains | `master` 1 (0 when muted), `sfxGain` 0.8, `musicGain` 0.32 (`A.init`) |

| OS setting | `prefers-reduced-motion` is not read |

## 3. Content: the options
| Row | Label (kid language) | Values | Default | What it changes |
|---|---|---|---|---|
| 1 | MUSIC | OFF 1 2 3 4 | 3 | `musicGain` = 0 / 0.10 / 0.20 / **0.32** / 0.45 |
| 2 | SOUNDS | OFF 1 2 3 4 | 3 | `sfxGain` = 0 / 0.30 / 0.55 / **0.80** / 1.00 |
| 3 | CALM MODE "Less shaking and sparkles" | OFF / ON | OS `prefers-reduced-motion` on first run, else OFF | see 4.2 |
| 4 | CARDS "Which hand do you play with?" | RIGHT / LEFT | RIGHT | see 4.3 |
| 5 | BUZZ | OFF / ON | ON | `buzz()` does nothing when OFF. Row shown only if `navigator.vibrate` exists |
| 6 | WHAT'S NEW | button | | opens `whatsNew()` for the current major.minor again |
| 7 | small print | | | "v1.0.0 · Art: Fluent Emoji (MIT) · Font: Poppins (OFL) · Sounds made by the game" |

Level 3 = today's gains, so nobody hears a change after the update. The mute button keeps working as master mute on top of both sliders; OFF on a row mutes only that channel.

Not in Settings (on purpose): difficulty (stays on the map), bedtime and limit (Parents, gated), account (Friends).

## 4. Signature rules
### 4.1 Audio (`js/audio.js`)
- New `A.setVolumes(music, sfx)`: keeps the levels on `A` and, if `ctx` exists, `setTargetAtTime` on `musicGain` / `sfxGain` (0.05 s). `init()` uses the stored levels instead of 0.32 / 0.8.
- Tapping a SOUNDS pill plays `A.thump()` at the new level; MUSIC is heard at once (the `calm` track runs on menus).
- Track gains (`TRACKS[name].gain`) unchanged.

### 4.2 Calm mode
| Effect | Calm mode |
|---|---|
| Camera shake (4 places) | off |
| Confetti | 25% of the particles |
| Endless pulses and wobbles (`repeat: -1` on buttons, chips, icons) | off: things stand still |
| Sky extras (shooting stars, rockets, UFO flyby) | off; still stars stay |
| Hit knock-back, squash, the rival's charge glow, BLOCK IT! / SAVE IT! hints | **kept** (they tell the kid what happens) |
| Comics, scene fades | kept |

Build note: one flag `PS.CALM`; a helper `pulse(scene, cfg)` that returns `null` when calm replaces the endless tweens one by one, and `shake()` guards the 4 calls. QA checks the big ones (section 8); a missed small wobble is S4 [?].

### 4.3 Left-handed cards
- LEFT mirrors the move cards: `x → W − x` for every card rect in `Battle.setup()`, portrait and landscape. Card order in the grid stays the same, so "Pillow Whack is the top-right card" for lefties.
- FOAM! / UMBRELLA!: base order mirrored (`sw` sign); HARD still swaps at random.
- Not mirrored: fighters (hero left, rival right), pep bars, back (top left) and mute (top right), booster picker, result panel.
- The layout is recomputed in `setup()`, so a rotation or a resumed duel picks up the setting.

### 4.4 Where it opens
- Title: a nav item **SETTINGS** (`j:gear`, order 6) after PARENTS. Portrait: 6 nav items at ~156 px spacing, the last at x ≈ 870, clear of mute at x = 1000. Landscape: 6th item at y ≈ 645 [? check against the TAP TO PLAY panel on D5].
- Not on the map or in duels (one place, no stray gear mid-duel).
- Bedtime / limit: Settings is allowed during bedtime [?] (it is not play); recommendation below.

### 4.5 EASY / NORMAL / HARD
No effect on difficulty.

## 5. Storage
- Device-only: `localStorage['plushsquad_prefs'] = { music: 3, sfx: 3, calm: false, hand: 'right', buzz: true }`. Not in `Save.data`, so cloud sync and `applyCloud()` (which replaces the whole save) never change it, and iPhone and iPad can differ.
- `muted` stays in the save as today (no change, no migration).
- Read once at boot before `A.init()`; written on every tap.
- Missing or broken JSON → defaults.

## 6. Rewards and progression
None. Settings never give XP, capsules or stickers.

## 8. Acceptance criteria and test ideas (for `qa-tester`)
1. SETTINGS on the title opens the screen on D1-D5; no text or button outside `0..W × 0..H`, no overlaps, all pills ≥ 90 px tall.
2. MUSIC / SOUNDS: each level sets `PSAudio.musicGain.gain` / `sfxGain.gain` to the table value; level 3 equals today's 0.32 / 0.8; OFF = 0; mute button still silences both and unmuting restores the chosen levels.
3. Settings survive a reload and a rotation; a cloud `applyCloud()` (mocked) does not change them; `plushsquad_v1` has no prefs fields.
4. Calm mode ON: no `cameras.main.shake` during a duel with Inferno Rain, SLAPSHOT and a crit; confetti count ≤ 25%; TAP TO PLAY and the BLOCK IT! button do not pulse; no rockets / shooting stars on the map; hit animations still play.
5. First run with `prefers-reduced-motion: reduce` (Playwright `reducedMotion`) → CALM MODE ON.
6. LEFT: in every battle mode (campaign, boss, toy, friend, Kraken) card x positions are mirrored on D1-D5, with 4, 5, 7 and 9 cards; tap targets still match the drawn cards; FOAM! / UMBRELLA! mirrored on NORMAL; rotation mid-duel keeps the mirror.
7. BUZZ row hidden when `navigator.vibrate` is missing; with a stub, OFF means no call.
8. WHAT'S NEW opens the current list; closing returns to Settings.
9. Regression: result tests for every mode; mute button on every scene.
