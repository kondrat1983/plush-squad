# Plush Squad docs

A gentle, funny pillow-fight game where a child's real plush toys become the heroes. Play it at [kondrat1983.github.io/plush-squad](https://kondrat1983.github.io/plush-squad/).

These pages are read from the repo, so they are always the latest version. Use the menu on the left (☰ on a phone) or the search box.
